# raw/

The original documents, exactly as received. **This folder is immutable** —
Claude only ever moves files *into* it, never edits or deletes what's already
here. Every claim in `wiki/` cites a file in here, so the wiki stays auditable
against the real paperwork.

Organize it into whatever categories match your household. A common starting
set, which mirrors the topical folders under `wiki/`:

```
raw/
├── employment/     -- offer letters, pay stubs, benefits enrollment
├── financial/      -- bank and brokerage statements, loans, taxes
├── home-property/  -- deeds, closing packets, permits, repairs, warranties
├── insurance/      -- policies and claims
├── medical-records/-- test results, visit summaries, EOBs
├── sensitive/      -- IDs, passports, birth certificates
└── vehicles/       -- titles, registrations, service records
```

Create the folders as you actually need them rather than all up front. Within a
category, group a related set into its own subfolder, e.g.
`home-property/HVAC - Lennox install 2026/`.
